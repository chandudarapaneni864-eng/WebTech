							HTML
HTML(Hyper text markup language) is standard language to create or structure the content on a webage, using Tags.

							Tags
Tags are special words written inside <>

2 types of Tags
1. Paired tags-opening and closing tags
		1. heading tags (h1,h2,h3,h4,h5)
		2. paragraph (p)
2. Unpaired tags-Self closing tags

						Attributes

Attributes are additional Information about the tags or given to tags.
1. Image tag example:
	 <img src="https://quantumzeitgeist.com/wp-content/uploads/pythonai.jpeg" height="200px" width="200px">

2. Creating A link using Anchor Tag:
	<a href="http://www.instagram.com">Visit Instagram</a>
	<a href="http://www.zomato.com">Go to Zomato</a>

						CSS
CSS stands for Cascading Style Sheets
CSS describes how HTML elements are to be displayed on screen

Applying styles:
1. Inline styles:
	<h1 style="color: red;background-color: yellow;">Hello students</h1>
2. Internal Styles
	<head>
		<style>
    h1{
      color: red;
      background-color: green;
    }
  </style>
	</head>
	<body>
		<h1>Welcome</h1>
	</body>
